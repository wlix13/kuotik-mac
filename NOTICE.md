# Сторонние материалы

Код в этом репозитории написан заново и распространяется по MIT (см. [LICENSE](LICENSE)).
Исключение — материалы учебного пособия, права на которые принадлежат их авторам.

## Справка

`kuotik_port/assets/help.zip` — справка программы «КУ ОТИК» (кафедра №12 НИЯУ МИФИ, автор
Е.Ф. Березкин и др.). Она переведена из `.chm` в HTML, формулы — из WMF в SVG. Права остаются у авторов;
файл включён для личного учебного использования и под MIT не подпадает.

Если права этого не допускают, удалите `kuotik_port/assets/help.zip`. Приложение запустится и без него:
вкладка «Общие сведения» покажет краткий текст, «Справка по работе» будет недоступна.

## Остальное

Названия работ, подписи полей и структура вкладок повторяют оригинальную программу — это нужно для
совместимости с методичками. Тексты заданий и контрольные вопросы в репозиторий не входят.
