# ЛР7 — корректирующие коды БЧХ (форма Form8)

Источники: `reference/chm/project7_1/7_1.htm` (теория, рис. 7.1–7.4, табл. 7.1–7.2),
`project7_2/7_2.htm` (подготовка: N = 7, T = 1), `project7_3/7_3.htm` (порядок выполнения),
`reference/lab7_questions.txt`, `reference/forms_all.txt` (блок Form8 `Left=486 Top=157`).

Формулы в справке — картинки `7_1.files/imageNNN.gif`; соответствующие `.wmz` — gzip-WMF,
текст извлечён разбором записей `META_EXTTEXTOUT` (по одной букве на запись, координаты
собирают строку). Оттуда дословно:

```
N = 2^m − 1
m = log₂(N + 1)          m = log₂(N·C₀ + 1)
G(x) = НОК [F_{1·C₀}(x), F_{3·C₀}(x), …, F_{i·C₀}(x), …, F_{Φ·C₀}(x)]
Φ ≤ D − 2,   D ≥ 2T + 1,   r ≤ m·T,   k ≥ (2^m − 1) − mT
F(β) mod p(z) ≡ 0        — определение минимального многочлена
p(z) = z⁴ + z + 1        — поле GF(2⁴) (табл. 7.1: α = z, β = z³, F(x) = x⁴+x³+x²+x+1)
G(x) = x⁹+x⁸+x⁷+x⁵+x⁴+x+1,  r = deg G = 9,  k = 12,  M = [21, 12]
g(x) = x¹⁰+x⁸+x⁵+x⁴+x²+x+1  (15, 5, 7)
H: строка i = (1, α^{i·C₀}, α^{2i·C₀}, …, α^{(N−1)i·C₀}),  i = 1…2T
S = A″·Hᵀ = (A + E)·Hᵀ = E·Hᵀ,   S_i = e(α^{i·C₀}) = e₀ + e₁α^{i·C₀} + …
S_{2i} = S_i²
M_ν·(s₁,…,s_ν)ᵀ = (S_{ν+1},…,S_{2ν})ᵀ,  M_ν = [S_{ν+i−j}],  s(z) = 1 + s₁z + … + s_νz^ν
det M_ν = 0 → редукция матрицы (ν уменьшается), иначе — система Крамера
корни s(z) обратны локаторам; позиции ошибок — обратные величины корней
```

## Назначение

Построение кода БЧХ по N и T (m, C₀, Φ, порождающий многочлен G(x), r, k), таблица
минимальных многочленов, систематическая порождающая матрица, ввод кодовой комбинации
A(x) и вектора ошибок E(x), исправление ошибок двумя алгоритмами (CS — циклический
сдвиг, PGZ — Питерсон–Горенстейн–Цирлер), построенное поле GF(2^m) и проверочная
матрица H.

## Что считается

### Параметры кода

```
m  = min{ m : N | 2^m − 1 },   C₀ = (2^m − 1)/N
Φ  = 2T − 1,   D = 2T + 1
G(x) = НОК[F_{1·C₀}, F_{3·C₀}, …, F_{(2T−1)·C₀}]
r = deg G,  k = N − r,  M = [N, k]
```

`F_{i·C₀}` — минимальный многочлен элемента α^{i·C₀} над GF(2): произведение
`(x + α^{i·C₀·2^j})` по циклотомическому классу (показатели по модулю 2^m − 1).
Если `r > N` или `k < 1` или `G(x) ∤ x^N + 1` — код не существует.

Значения m и C₀ по N (совпадают с ветвлением `ComboBox1Exit`):

| N | 3 | 5 | 7 | 9 | 15 | 21 | 31 | 63 |
|---|---|---|---|---|---|---|---|---|
| m | 2 | 4 | 3 | 6 | 4 | 6 | 5 | 6 |
| C₀ | 1 | 3 | 1 | 7 | 1 | 3 | 1 | 1 |

Существование кодов по T (проверено построением):

### Кодирование и матрица

```
A(x) = u(x)·G(x)               — несистематическое кодирование
A(x) = u(x)·x^r + (u(x)·x^r mod G(x))   — систематическое (строки матрицы)
A″(x) = A(x) + E(x)            — принятая комбинация
```

Строка i систематической матрицы: единица в разряде N−1−i, в младших r разрядах —
остаток от деления x^{N−1−i} на G(x). Для (21, 12) остатки совпадают с рис. 7.3:
111011001, 100110101, 101000011, 101111000, 010111100, 001011110, 000101111,
111001110, 011100111, 110101010, 011010101, 110110011.

### Синдромы

```
S_i = A″(α^{i·C₀}) = e(α^{i·C₀}),  i = 1…2T;   S_{2i} = S_i²
```

`S = 0` ⇔ ошибок нет (или комбинация — кодовое слово). Синдром зависит только от
вектора ошибок. Матрица H — 2T строк по N элементов `α^{i·C₀·j}`.

### Метод CS (циклический сдвиг)

Делим A″(x) на G(x); если вес остатка W > T — циклический сдвиг влево на 1 разряд и
снова деление. При W ≤ T: складываем последнее делимое с остатком и сдвигаем результат
вправо на число сделанных сдвигов. Если за N сдвигов остаток с W ≤ T не встретился —
метод зациклился (ошибки стоят на равных расстояниях), исправление невозможно.

### Метод PGZ

1. ν = T, синдромы S₁…S₂T.
2. Матрица Ньютона `M_ν = [S_{ν+i−j}]`; при det M_ν = 0 — редукция (ν ← ν−1).
3. Решение системы по Крамеру → s₁…s_ν, локатор `s(z) = 1 + s₁z + … + s_νz^ν`.
4. Подстановка всех α^{C₀p}, p = 0…N−1; корни s(z) обратны локаторам, позиции
   p = −log_{α^{C₀}}(корень).
5. Инверсия разрядов; если корней меньше ν (или синдромы не согласованы с локатором) —
   ошибка обнаружена, но не исправлена.

## Численные примеры из справки

### CS: (21, 12), T = 2

A(x) = 110000000000011101100, E(x) = 110000000000000000000,
A″(x) = 000000000000011101100.

| цикл | делимое | остаток | W |
|---|---|---|---|

### PGZ: (15, 5, 7)

p(x) = x⁴ + x + 1, g(x) = 10100110111, u(x) = 101100100011110 (делится на g),
e(x) = 001000001000001, r(x) = u + e = 100100101011111.

Вычисленные синдромы: S₁ = α, S₂ = α², S₃ = α⁸, S₄ = α⁴, S₅ = 1, S₆ = α
(проверено: S₂ = S₁², S₄ = S₂², S₆ = S₃²). Локатор третьей степени даёт корни,
обратные локаторам разрядов 0, 6 и 12; после инверсии этих разрядов получается
u(x). Совпадает с выводом справки («Исправляем разряды 0, 6, 12»).

**Расхождение.** В справке синдромы напечатаны как α², α⁴, α⁸, α¹, 1, α² (набор
сдвинут на одну степень и нарушает S₄ = S₂²); при заданных там же p(x), g(x), u(x)
и e(x) получаются значения выше. В порте считаются синдромы по определению,
расхождение зафиксировано в `check_lab7.py`.

### Зацикливание CS: (15, 5)

g(x) = 10100110111, E(x) = x¹⁴+x¹²+x¹⁰+x⁸+x⁶+x⁴+x²+1: за 15 сдвигов вес остатка

* Ввод A(x) в форме — вручную; в порте дополнительно можно отметить строки
  порождающей матрицы и сложить их кнопкой «Сложить выбранные строки → A(x)»,
  как предписывает порядок выполнения.
* «Динамика» CS показывает не только протокол, но и график веса остатка по циклам
  с порогом T — в форме `Memo1` содержит только текст.
* Нумерация разрядов — младший разряд x⁰ (как в справке: «нумерация разрядов 0…N−1»).

## Ограничения

* T = 1…7, N из набора; при r > N или k < 1 форма сообщает «БЧХ не существует».
* A(x) принимается только как кодовое слово (делится на G(x) нацело), T не больше
  исправляющей способности выбранного кода.
* CS не гарантирует исправление всех векторов (зацикливание) — это свойство метода,
  а не ошибка порта; PGZ исправляет все векторы кратности ≤ T.
* Ошибки кратности > T обнаруживаются (синдром ≠ 0), но могут быть «исправлены»
  в другое кодовое слово — так работает любой ограниченно-дистанционный декодер;
  в порте такие случаи помечаются как «обнаружено и исправлено, но комбинация
  отличается от исходной» только при сравнении с введённой A(x).
