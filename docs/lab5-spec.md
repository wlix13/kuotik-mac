## Назначение

Сжатие двоичных n-блоков четырьмя обратимыми методами при частично известной (КДС, АПК, ИПП) и
неизвестной (УК) статистике источника: кодовое слово, длина, коэффициент сжатия, избыточность,
проверка декодирования; семейства `Kсж(p)` при фиксированном n и чувствительность к расположению
единиц.

## Обозначения

`N = n` — длина блока, `K` — число единиц, `p = K/N`, `L` — длина кодового слова в битах,
`L(N)` — длина одного адреса/серии, `P(K) = K/N`, `B(K)` — номер блока для УК.

```
L_ед = ⌈log₂(n+1)⌉                  длина позиции/серии, целочисленно: (n).bit_length()
H(p) = −p·log₂p − (1−p)·log₂(1−p)    бит/символ
Kсж  = N/L,   L_симв = L/N,   R = L_симв − H,   η = H/L_симв = H·N/L
```

Две границы (Memo и таблица сравнения):

* `1/H(p)` — предел Шеннона для источника с известной статистикой (`L ≥ N·H`);
* `n/log₂C(n,K)` — предел для класса блоков с данным K (энтропия класса `log₂C(n,K)` бит/блок).

Методы не являются префиксными кодами блоков (длина слова не передаётся), поэтому для отдельного
блока `Kсж` может превышать `1/H(p)`; граница относится к средней длине по классу блоков.

## Методы

### АПК — адресно-позиционное кодирование

Позиции единиц нумеруются 1…N от начала блока, каждая передаётся равномерно `L_ед` битами:

```
word = bin(i₁, L_ед) ‖ bin(i₂, L_ед) ‖ … ‖ bin(i_K, L_ед)
L = K·L_ед,   Kсж = N/(K·L_ед)
```

`K = 0` — одно слово `0` длиной `L_ед` (как в форме), `Kсж = N/L_ед`. Длина зависит только от K.
Декодирование: K чисел → позиции, проверяются `1 ≤ i_j ≤ N` и возрастание.

### КДС — кодирование длин серий

Высоковероятный символ — нуль. Серия длины `s = 1…n` имеет префиксный код `0^{s−1}1` длины `s`,
серия `n+1` (блок из одних нулей) — код `0`. В форме длина серии передаётся равномерно `L_ед`
битами, поэтому слово — набор чисел:

```
v₁ = i₁,  v_j = i_j − i_{j−1} (j = 2…K),  v_{K+1} = N − i_K + 1  (если i_K < N)
word = bin(v₁,L_ед) ‖ … ,   t = K или K+1,   L = t·L_ед,   Kсж = N/L
K = 0:  word = bin(0, L_ед),  L = L_ед
```

Хвост `N − i_K + 1` передаётся, только если блок не кончается единицей, — единственный источник
чувствительности КДС к расположению при том же K. Декодирование: накопление длин даёт позиции,
последнее число (при `t = K+1`) проверяется как длина хвоста.

### ИПП — итерации простых подстановок (Блох)

К строке применяется подстановка `00 → 0`, `01 → 11`, `1 → 10`; одиночный нуль в конце строки
остаётся нулём. Итерации идут, пока длина убывает или строка меняется при той же длине; при
удлинении сохраняется предыдущий результат; не более 10 итераций.

```
L = |word|,   Kсж = N/L,   L ≤ N   (метод не удлиняет блок)
```

Обратное преобразование — по шагам: `0 → 00`, `10 → 1`, `11 → 01`; длины шагов берутся из трассы
кодирования (подстановка с одиночным концевым нулём без этой информации не декодируется
однозначно; в форме декодирование и не предусмотрено).

### УК — универсальное кодирование (Бабкин)

```
b = Σ_{j=1…K} C(i_j − 1, j),    0 ≤ b ≤ C(N,K) − 1
l₁ = ⌈log₂(N+1)⌉,   l₂ = ⌈log₂C(N,K)⌉,   l₂ = 0 при K = 0, K = N или N = 1
word = bin(K, l₁) ‖ bin(b, l₂),   L = l₁ + l₂,   Kсж = N/L
```

Декодирование: для `j = K…1` в столбце `j` ищется наибольшее `C(i−1, j) ≤ b`, вычитается,
`i_j = i`. Длина зависит только от K.

## Пример из справки: n = 8, блок 01101101

`K = 5`, позиции 2, 3, 5, 6, 8, `L_ед = ⌈log₂9⌉ = 4`.

| Метод | Слово | L | Kсж |
|---|---|---|---|
| АПК | `0010 0011 0101 0110 1000` | 20 | 0.400 |
| КДС | `0010 0001 0010 0001 0010` (серии 2,1,2,1,2) | 20 | 0.400 |
| ИПП | `01101101` (подстановка даёт `1110111011` — длиннее, результат сохранён) | 8 | 1.000 |
| УК | `0101 100000` | 10 | 0.800 |

УК: `b = C(1,1)+C(2,2)+C(4,3)+C(5,4)+C(7,5) = 1+1+4+5+21 = 32`;
`L = 4 + ⌈log₂56⌉ = 4 + 6 = 10`. Декодирование 32: `32−21=11`, `11−5=6`, `6−4=2`, `2−1=1`,
`1−1=0` → позиции 8, 6, 5, 3, 2. Числа совпадают с `image060.gif` (`4+6`) и текстом справки.

Крайние случаи для n = 8:

| Блок | K | АПК | КДС | ИПП | УК |
|---|---|---|---|---|---|
| `00000000` | 0 | `0000`, L = 4 | `0000`, L = 4 | `0`, L = 1 | `0000`, L = 4 |
| `11111111` | 8 | L = 32 | L = 32 | L = 8 | `1000`, L = 4 |
| `10101010` | 4 | L = 16 | L = 20 (хвост) | L = 8 | L = 11, b = 20 |

## Оценка длины для n = 100 (табл. 5.2 справки)

| K | 1 | 2 | 3 | 4 | 10 | 20 |
|---|---|---|---|---|---|---|
| `l₁+l₂` по справке | 7+7 | 7+13 | 7+18 | 7+23 | 7+45 | 7+70 |
| `Kсж = 100/L` | 7.14 | 5.00 | 4.00 | 3.33 | 1.92 | 1.30 |
| точный `⌈log₂C(100,K)⌉` | 7 | 13 | 18 | 22 | 44 | 69 |

`l₁ = ⌈log₂101⌉ = 7`. Для K = 1…3 таблица совпадает с точным расчётом; для K = 4, 10, 20 в
методичке округление вверх выполнено с запасом на единицу — программа считает точно.

## Чувствительность к расположению единиц (n = 10, K = 1)

| Метод | Длины слов по всем расположениям |
|---|---|
| АПК | только 4 — зависит от K |
| УК | только 8 — зависит от K |
| КДС | 4 или 8 (позиция единицы в конце блока требует передачи хвоста) |
| ИПП | 3, 4, 5, 6 — зависит от расположения |

## Ограничения полей и валидация

* Блок — строка из `0`/`1`, длина 1…64 (`MAX_N`), ввод фильтруется валидатором `[01]*`.
* Пустой блок — «Не выбран исследуемый блок!»; длина > 64 — «Неверная длина блока: N > 64»;
  посторонние символы — «Допустимы только символы 0 и 1». При ошибке расчёт не выполняется.
* `K = 0`, `K = N`, `N = 1` — особые случаи: `l₂ = 0` у УК, одно слово `0` у АПК/КДС.
* `L_ед = n.bit_length()`, что равно `⌈log₂(n+1)⌉` и совпадает с ветвлением формы
  «n+1 — степень двойки».
* ИПП — не более 10 итераций, при удлинении сохраняется предыдущий результат.
* «Блок №1»/«Блок №2» — два сохранённых блока; активный запоминается при кодировании.

## Отличия от исходной формы

* Memo «Результат сжатия» формируется программно: блок, позиции/серии (или B(K)), слово с
  разбивкой по частям, L, Kсж, R, η, обе границы, результат проверки декодирования; в форме
  Memo содержал только слово.
* Добавлена проверка декодирования (в форме было только кодирование).
* Графики — matplotlib вместо TImage: семейства `Kсж(p)` для двух n и разброс `Kсж` по всем
  расположениям единиц при фиксированных n, K.
* Порядок частей слова УК (`K`, затем `B(K)`) и формулы `L`, `Kсж` взяты из обработчика 0x4ee4c8.
* Прежняя статистическая часть (энтропия букв, Шеннон–Фано, Хаффман, блоки по n букв) убрана:
  в Form6 её нет, Шеннон–Фано и Хаффман остаются только в теории как методы для полностью
  известной статистики.
