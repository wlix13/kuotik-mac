# ЛР3 — дискретизация непрерывных сигналов по времени (форма fSpektr)

Источники: `reference/lab3_1.txt` (теория), `lab3_2.txt` (подготовка), `lab3_3.txt` (порядок),
`forms_lab3.txt` + `forms.json:fSpektr` (контролы), декомпиляция `re/dec/functions` (имена методов
срезаны, поэтому формулы сверены по теории, а не по псевдокоду).

## Назначение

Стенд «генератор → АЦП → идеальный ФНЧ → осциллограф/ЭВМ». Пользователь задаёт сигнал, интервал
дискретизации, размер кванта и частоту среза ФНЧ; программа строит непрерывный, дискретный,
квантованный и восстановленный сигналы, амплитудный спектр, АКФ и спектральную плотность мощности.

## Сигналы генератора

Тип выбирается из списка: `Гарм. сигнал`, `Прям. импульсы`, `Шум`, `Смешанный`.
Справка перечисляет шесть видов, но в форме четыре типа; одиночный импульс, пачка и импульс ВЧ
получаются выбором периода/длительности относительно длины записи `T = N·Δt` (п. 7–8 порядка).

Все сигналы — функции времени `t` в секундах, амплитуды в вольтах.

- Гармонический: `x(t) = A·sin(2π f (t − φ))`, `A` — амплитуда, В; `f` — частота, Гц;
  `φ` — сдвиг в мс (поле «Фаза, мс» в форме), переводится в секунды.
- Прямоугольные импульсы: `x(t) = A·[ (t mod Tи) < τ ]`, `Tи` — период, мс; `τ` — длительность, мс;
  при `Tи > T` в записи один импульс, при `τ < Tи` — пачка.
- Гауссов шум: `x[n] = m + σ·ξ`, `ξ ~ N(0,1)`, `m` — мат. ожидание, В; `σ²` — дисперсия, В².
  Генератор детерминирован (seed=0), чтобы графики и проверки повторялись.
- Смешанный: сумма гармоники, последовательности импульсов и шума с теми же параметрами.

Длина сигнала `N` — число отсчётов: 64, 128, 256, 512, 1024 (по умолчанию 256).

## АЦП

- Интервал дискретизации `Δt`, мс (маска `9999,99` в форме); диапазон 0.01…9999.99 мс.
- Частота дискретизации `Fд = 1/Δt`, Гц — вычисляется, в форме поле только для чтения.
- Размер одного кванта `Δ`, В; 0 — квантование выключено. Квантование: `xq = Δ·round(x/Δ)`,
  ошибка не больше `Δ/2`.
- Отсчёты: `x[n] = x(n·Δt)`, `n = 0…N−1`.

## Идеальный ФНЧ

Частота среза `Wc`, рад/с (в форме маска `999999,99`); по умолчанию `Wc = π/Δt`, т.е. граница
Найквиста. Импульсная характеристика `h(t) = (Wc/π)·sinc(Wc·t/π)`, `sinc(x) = sin(πx)/(πx)`.
Восстановление по отсчётам: `x_восст(t) = Δt·Σ x[n]·h(t − n·Δt)`.
При `Wc = π/Δt` это ряд Котельникова–Шеннона: `x_восст(n·Δt) = x[n]`, а для гармоники с `f < Fд/2`
восстановление совпадает с исходной синусоидой (кроме краёв записи).
Флажок «Показывать составляющие» рисует отдельные слагаемые `Δt·x[n]·h(t − n·Δt)`.
Флажок «Режим фильтра» включает/выключает восстановление.

## Параметры процесса (только чтение)

Верхняя частота спектра сигнала `Fв`:
гармоника — `f`; импульсы — `1/τ` (первый нуль спектра прямоугольного импульса);
шум — `Fд/2`; смешанный — максимум из составляющих.

- `Wc_опт = 2π·Fв`, рад/с — «Ограничение спектра исходного сигнала, Wc=2πFc».
- `Δt_опт = 1/(2·Fв)`, с → мс — «Интервал дискретизации, мс».
- Критерий Котельникова: `Fд ≥ 2·Fв`. Иначе — предупреждение и наложение (алиасинг).

Граница Найквиста `Fн = Fд/2`. Частота `f > Fн` наблюдается как зеркальная копия
`f_ал = |f − Fд·round(f/Fд)|` в полосе `0…Fн` (для `f = 1300 Гц`, `Fд = 1000 Гц` → 300 Гц).

## Амплитудный спектр

ДПФ: `X[k] = Σ x[n]·e^(−j2πkn/N)`. Односторонний амплитудный спектр:
`A[0] = |X[0]|/N`, `A[k] = 2|X[k]|/N` для `k = 1…N/2−1`, В. Шаг по частоте `Δf = Fд/N`.
Синусоида с амплитудой `A` и целым числом периодов в записи даёт один отсчёт `A[k] = A`.

Спектр дискретного сигнала периодичен: `X(f + Fд) = X(f)`. На вкладке рисуются три периода
(`−Fд…2Fд`), пунктиром — граница `Fд/2`; это и есть «периодические копии» спектра.

## АКФ

`R[m] = (1/N)·Σ_{n=0}^{N−1−m} x[n]·x[n+m]`, `m = 0…N/2`, задержка `τ = m·Δt` (мс), единицы В².
Для синусоиды `R(τ) = (A²/2)·cos(2πfτ)`, `R(0) = A²/2`.

## СПМ

Периодограмма: `S[k] = |X[k]|²/(N·Fд)` с удвоением внутренних бинов (односторонняя), В²/Гц,
`k = 1…N/2−1`; `S[0]` без удвоения.
`Σ S[k]·Δf = (1/N)·Σ x[n]²` (средняя мощность).
Белый шум с дисперсией `σ²` даёт равномерную СПМ со средним `2σ²/Fд` в полосе `0…Fд/2`.

## Соответствие контролов формы

`cTypeSig` → тип сигнала; `seDuration` → N; `seSinAmp/seSinFeq/seSinFaza` → A, f, φ;
`seImAmp/seImPeriod/seImDur` → A, Tи, τ; `seNoiceMat/seNoiceDisp` → m, σ²;
`seDiskretInterval` → Δt; `seDiskret` → Fд (read-only); `seKvant` → Δ;
`seBorder` → Wc; `cbConsistSinus` → показывать составляющие; `CheckFiltrMode` → режим фильтра;
`cbCase` (мс/мкс) → единицы времени осциллографа; `eGetBorder`, `eDiskret` → оптимальные Wc и Δt.

## Проверяемые утверждения (scripts/check_lab3.py)

1. `Fд = 1000/Δt(мс)`, `Fн = Fд/2`.
2. Пик спектра гармоники 125 Гц при `Fд = 1000 Гц` — на 125 Гц, амплитуда ≈ A.
3. Наложение: 1250 Гц при `Fд = 1000 Гц` даёт пик 250 Гц.
4. `X(f + Fд) = X(f)` для ДПФ (периодические копии).
5. Восстановление при `Wc = π/Δt` проходит через отсчёты (ошибка < 1e-9) и повторяет синусоиду
   в середине записи.
6. Квантование с шагом Δ: `max|xq − x| ≤ Δ/2`.
7. АКФ синусоиды: `R(0) ≈ A²/2`, `R(T/4) ≈ 0`.
8. СПМ белого шума: средний уровень ≈ `2σ²/Fд`.
9. При `Fв > Fн` статус содержит предупреждение о теореме Котельникова.
10. «Очистить» очищает данные и графики.
