## Назначение

Две части: (1) спектральные характеристики случайных процессов — реализации, АКФ, СПМ и пара
Хинчина–Винера; (2) синтез обнаружителя постоянного сигнала `x(t)=a` на фоне гауссовой помехи
`N(m, σ)` при однократном отсчёте для трёх решающих правил и исследование влияния априорных данных.

## Модель

Сигнал: `a` — амплитуда (В), `m` — среднее помехи (В), `σ` — СКО помехи (В). Гипотезы:
`a1` — сигнала нет: `x ~ N(m, σ)`; `a2` — сигнал есть: `x ~ N(m+a, σ)`.

Плотности: `f(x|a1) = φ((x−m)/σ)/σ`, `f(x|a2) = φ((x−m−a)/σ)/σ`, `φ(u)=e^{−u²/2}/√(2π)`.
Отношение правдоподобия:

```
L(x) = f(x|a2)/f(x|a1) = exp( a·(x−m)/σ² − a²/(2σ²) )
```

Решающее правило: принимаем `a2`, если `L(x) > λ`; иначе `a1`. Порог по отсчёту:

```
Xп = m + a/2 + (σ²/a)·ln λ          (решение L(Xп) = λ)
```

| Правило | λ | Порог Xп |
|---|---|---|
| 1. Максимум правдоподобия (Фишер) | `1` | `m + a/2` |
| 2. Идеальный наблюдатель (Зигерт–Котельников) | `p(a1)/p(a2)` | `m + a/2 + (σ²/a)·ln(p1/p2)` |
| 3. Минимальный риск (Байес) | `p(a1)·r12 / (p(a2)·r21)` | `m + a/2 + (σ²/a)·ln(p1·r12/(p2·r21))` |

Области: `X1 = (−∞, Xп)` → гипотеза `a1`, `X2 = [Xп, ∞)` → `a2`. `r12` — потери, если принят `a1`
при наличии сигнала; `r21` — наоборот; верные решения — 0.

Вероятность ошибки и средний риск (Q-функция `Q(u)=0.5·erfc(u/√2)`, `Φ(u)=1−Q(u)`):

```
Pош = p1·Q((Xп−m)/σ) + p2·Φ((Xп−m−a)/σ)
r   = p1·r12·Q((Xп−m)/σ) + p2·r21·Φ((Xп−m−a)/σ)
```

Порог `Xп*`, минимизирующий `Pош` (и `r`), совпадает с формулой выше для соответствующего `λ` —
это проверяется перебором по сетке.

Апостериорные вероятности (вкладка «Исследование», как в панели Panel4):

```
P(a1|X1) = p1·Φ(u1) / (p1·Φ(u1) + p2·Φ(u2))
P(a2|X2) = p2·(1−Φ(u2)) / (p1·(1−Φ(u1)) + p2·(1−Φ(u2)))
u1 = (Xп−m)/σ,  u2 = (Xп−m−a)/σ
```

Проверка реализации `X`: если `X > Xп` — принята `a2`, иначе `a1`; для этой реализации выводятся
`P(a1|X1)`, `P(a2|X2)`, средняя ошибка `Pош` и риск `r`.

## Спектральные характеристики

Три процесса (вкладка «Спектральные характеристики»):

| Процесс | Реализация | АКФ `R(τ)` | СПМ `Φ(ω)` |
|---|---|---|---|
| Постоянный уровень | `x(t)=A` | `A²` | `2πA²·δ(ω)` |
| Стационарный (RC/АР-1) | `y[n]=ρ·y[n−1]+σ√(1−ρ²)·w[n]`, `ρ=e^{−αΔt}` | `σ²·e^{−α|τ|}` | `2ασ²/(α²+ω²)` |
| «Белый» шум | `x[n]=σ·w[n]` | `σ²·δ(τ)` | `σ²` (постоянна) |

Связь — преобразования Хинчина–Винера: `Φ(ω)=∫R(τ)e^{−jωτ}dτ`, `R(τ)=(1/2π)∫Φ(ω)e^{jωτ}dω`,
`R(0)=(1/2π)∫Φ(ω)dω` = средняя мощность = дисперсия. Для RC-процесса `∫Φ dω/2π = σ²`.

Дискретная периодограмма: `S[k]=|X[k]|²/(N·Fд)` с удвоением внутренних бинов (односторонняя), В²/Гц;
средний уровень белого шума `2σ²/Fд`; `Σ S[k]·Δf = (1/N)Σx²`.

Параметры: тип процесса, `σ`, `α` (1/с, ширина спектра), `N` (256…4096), `Fд` (Гц).

## Согласованный фильтр

Прямоугольный импульс `s(t)=A` при `0≤t≤T`, белый шум с односторонней СПМ `N0`.
`h(t)=s(t0−t)`, `t0=T`; выход `y(t)=∫x(τ)h(t−τ)dτ`. В момент `t0`:

```
y(t0) = ∫s²(τ)dτ·A = E = A²T,   SNR(t0) = 2E/N0
```

Максимум `|y(t)|` достигается при `t=t0`; любая другая `h` даёт меньшее отношение сигнал/шум
(проверяется сравнением с фильтром вдвое короче).

## Проверяемые утверждения (scripts/check_lab4.py)

1. Структура: 4 внешние вкладки, 4/2/2/2 внутренних.
2. Нормировка плотности: `∫f(x|a1)dx = ∫f(x|a2)dx = 1`; `∫L(x)·f(x|a1)dx = 1`.
3. Порог максимума правдоподобия `Xп=m+a/2`, `L(Xп)=1`.
4. Порог идеального наблюдателя — корень `p1·f1=p2·f2` (сверка с бисекцией).
5. Порог минимального риска — корень `p1·r12·f1=p2·r21·f2`.
6. `Pош` по формуле совпадает с численным интегрированием плотностей.
7. `Xп*` минимизирует `Pош` (перебор по сетке).
8. `P(a1|X1)+P(a1|X1)`-связка: при `p1=p2` и `X=Xп` апостериорные = 0.5; при `p1≠p2` — `p1`.
9. Кнопка «Проверить» принимает верный порог и отвергает неверный; «Обнулить» чистит вердикт.
10. RC-процесс: численное `Φ(ω)` из `R(τ)` = `2ασ²/(α²+ω²)`, `∫Φdω/2π=σ²` (Винер–Хинчин).
11. Выборочная АКФ АР-1 ≈ `σ²e^{−α|τ|}`, `R(0)` ≈ дисперсия.
12. Белый шум: `R[0]≈σ²`, СПМ ровная, средний уровень `2σ²/Fд`.
13. Постоянный уровень: `R(τ)=A²`, мощность по периодограмме = `A²`.
14. Согласованный фильтр: максимум выхода при `t=t0`, `SNR=2E/N0`, короче фильтр — хуже.
