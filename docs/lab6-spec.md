## Назначение

Расчёт информационной пропускной способности `C = max_{p(x)} H(X;Y)` трёх моделей
двоичного канала (ДК, ДСК, ДСКС), проверка поверхности `C = F[p1,p2]` и `C = F[p,q]`,
расчёт `C` для циклического кода `(N,k)` в режимах обнаружения и коррекции ошибок и
сопоставление с каналом без контроля.

## Что считается

### ДК (двоичный несимметричный канал)

Матрица `[[1−p1, p1], [p2, 1−p2]]`, `z = P(x1)`, `s = 1−p1−p2`.

```
B  = h(p2) − h(p1),  h(p) = −p·ln p − (1−p)·ln(1−p)          (наты, как в форме)
D  = 1 + exp(−B/s)
Zo = (1 − p2·D)/(s·D)                                        (= z, максимизирующее I)
P(y1) = p2 + s·Zo
C  = H(P(y1)) − [Zo·H(p1) + (1−Zo)·H(p2)]                    (биты)
```

Условие экстремума `s·ln((1−u)/u) = h(p1) − h(p2)` даёт `u = 1/D`, откуда и берётся `Zo`.
При `p1 = p2 = p` формула сводится к `C = 1 − H(p)`.
В форме `B`, `D`, `Zo` выводятся как «промежуточные результаты», `C` — как
`H(X;Y)`; `Z = P(x1) = Zo` печатается отдельной строкой.

**Расхождение с оригиналом.** В процедуре 0x4fc898 условная энтропия считается как
`Zo·H(p2) + (1−Zo)·H(p1)`, то есть веса `Zo` и `1−Zo` перепутаны местами относительно
`P(y1) = p2 + s·Zo`. При `p1 = p2` это незаметно, при `p1 ≠ p2` занижает `C`:
для `p1 = 0.05, p2 = 0.125` оригинал даёт `0.57157`, истинный максимум — `0.58173`
(проверяется перебором `z`). В порте считается правильный максимум; функция
`dk_capacity_legacy()` воспроизводит число оригинала для сверки.

### ДСК и ДСКС

ДСК — частный случай `p1 = p2 = p`: `C = 1 + p·log₂p + (1−p)·log₂(1−p) = 1 − H(p)`.

ДСКС: канал симметричен по входу, оптимальное распределение равномерно (`Zo = 0.5`,
в форме выводится константой), и

```
C = (1−q)·[1 − log₂(1−q)] + (1−p−q)·log₂(1−p−q) + p·log₂p
```

Крайние случаи процедуры 0x4fc26c: `p = 0` → `C = 1 − q` (ДСКС вырождается в канал со
стиранием), `q = 1` → `C = 0`, `p + q → 0` → `C → 1`. Значение ограничивается отрезком
`[0, 1]`.

### Циклический код (N, k)

```
p_но = 2^−(N−k)·p_ош,   p_оо = [1 − 2^−(N−k)]·p_ош,   p_пп = 1 − p_но − p_оо
```

`p_но` подставляется в поле `p`, `p_оо` — в поле `q` задачи 1 (обнаружение) и задачи 2
(обнаружение + коррекция); задача 3 берёт те же числа как `p1`, `p2` ДК без контроля.
Варианты `(N,k)` — `(7,4)`, `(15,11)`, `(31,26)` (строки `КОД (7,4)`, `КОД (15,11)`,
`КОД (31,26)` в `.exe`).

| (N,k) | p_ош | 2^−(N−k) | 1 − 2^−(N−k) | C (справка) |
|---|---|---|---|---|
| (7,4) | 0.05 | 0.125 | 0.875 | 0.94532 |
| (15,11) | 0.05 | 0.063 | 0.937 | 0.99954 |
| (31,26) | 0.05 | 0.031 | 0.969 | 0.99999 |

Столбцы `2^−(N−k) = 1/8, 1/16, 1/32` и `1 − 2^−(N−k)` воспроизводятся точно (в справке
округление до трёх знаков: `0.0625 → 0.063`, `0.03125 → 0.031`).

**Столбец C справки формулами не воспроизводится.** Проверены все разумные подстановки
для каждой строки (`p, q` = `p_ош, 2^−(N−k)`; `p_но, p_оо`; перестановки; формулы ДК и
ДСКС):

| (N,k) | ДСКС(`p_ош`, `2^−(N−k)`) | ДСКС(`p_но`, `p_оо`) | ДК(`p_но`, `p_оо`) | справка |
|---|---|---|---|---|
| (7,4) | 0.59850 | 0.90190 | 0.84298 | 0.94532 |
| (15,11) | 0.65588 | 0.92283 | 0.84831 | 0.99954 |
| (31,26) | 0.68470 | 0.93486 | 0.85187 | 0.99999 |

Ни одна модель не даёт чисел справки; более того, `C ≤ 1 − q = 0.875` для ДСКС при
`q = 0.125`, а в справке `0.94532 > 0.875`, то есть столбец C взят из другого расчёта
(вероятно, из более ранней версии программы). В порте считаются значения по формулам
6.1–6.3; воспроизводимые столбцы таблицы (q и 1−q) проверяются в `check_lab6.py`
численно, расхождение столбца C зафиксировано там же.

## Ограничения

* `p1, p2, p, q ∈ [0, 1]`, дополнительно `p1 + p2 < 1` (ДК) и `p + q < 1` (ДСКС и задачи).
* `s ≤ 0` — пропускная способность не определена (в форме выводится «Неопределенность»),
  на поверхности такие точки не рисуются (`NaN`).
* Поле `TMaskEdit` принимает ровно пять знаков после точки; ввод больше 1 или сумма
  вероятностей больше 1 отклоняется сообщением, результаты очищаются.
* Поверхности строятся по сетке 15×17 = 255 точек — столько же строк в `resulttable`
  оригинала; на боковых гранях `p1 + p2 = 1` (или `p + q = 1`) `C = 0`.
* `C ≤ min(H(X), H(Y)) ≤ 1`; проверяется в `check_lab6.py` вместе с `C = 1 − H(p)` для ДСК
  и совпадением аналитического `C` с численным максимумом по `z`.
